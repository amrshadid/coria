# The services of the API contract (api/proto) that the server does not
# serve yet, one full service name per line; "#" starts a comment.
#
# A contract is merged and reviewed as a contract before its handlers are
# written, so for a while a service is in the proto files with nothing behind
# it. Until a handler exists the server answers each of its methods
# UNIMPLEMENTED to an authenticated caller, as it answers any service it does
# not have.
#
# Read by the Go tests of internal/api and internal/server/servertest and by
# scripts/prove/steps.py, which check each name the other way round: a listed
# service must be defined by a proto file, must have no method in the
# server's table, and must answer UNIMPLEMENTED; every service not listed is
# held to its Role lines and to every check of a served method.
#
# A line is removed in the change that serves its service; the tests fail
# until it is.
